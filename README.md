# Secure Offline PDF Reader

### Flutter Android app · Public engineering case study

[Secure Offline PDF Reader on Google Play](https://play.google.com/store/apps/details?id=pdf.pdfreader.pdfviewer.pdfeditor.freepdf&pcampaignid=web_share) · [Portfolio](https://rahulrwt99.github.io/) · [LinkedIn](https://www.linkedin.com/in/rahul-rawat-00396a1a1)

Secure Offline PDF Reader is a published Flutter Android utility focused on local PDF and image workflows. Its core document-processing experience is designed to run on the device, avoiding dependence on a remote processing service.

> **Repository scope:** This is a public case study that describes the product and engineering scope without exposing private production source code or user data.

## Product highlights

### PDF tools

- View and compress PDFs
- Lock and unlock PDFs
- Reorder and delete pages
- Other local PDF editing workflows

### Image tools

- JPG/PNG conversion
- Image resizing and compression
- Image-to-document utility workflows

## Engineering work

| Area | Work represented |

| Release delivery | Android packaging, maintenance, and Google Play release lifecycle |

## Why local-first matters

Personal documents are sensitive. Designing core processing to happen on-device reduces cloud dependency and supports users who need useful document tools even when a remote service is unavailable.
