# Secure Offline PDF Reader

### Offline-focused Flutter application published for Android

Secure Offline PDF Reader is a complete Android product centered on local document reading and an offline-first product direction.

[View on Google Play](https://play.google.com/store/apps/details?id=pdf.pdfreader.pdfviewer.pdfeditor.freepdf&pcampaignid=web_share)

## Product delivery

- Built as an offline-focused user-facing application
- Developed with Flutter for Android
- Carried through the complete release lifecycle
- Published and publicly available on Google Play

## Engineering focus

The project demonstrates practical mobile engineering and the ability to take a focused product from implementation to public distribution.

## Technology

`Flutter` · `Dart` · `Android` · `Offline-first product design`

## Repository scope

This repository is a public product case study focused on the application and its delivery lifecycle.
